# Internationalization Requirements

**Version**: 1.1.0
**Last Updated**: 2026-10-17

## Overview

The product targets Vietnamese households and also supports English. UI text, dates and the purifier catalog are localized on both platforms.

## Requirements

### FR-008: Internationalization
- **Priority**: Medium
- **Status**: Done
- **Acceptance criteria**:
  - [x] UI available in Vietnamese and English on web and iOS
  - [x] Web: language switcher in the header; the choice is stored in `localStorage`; first visit uses the browser language; fallback is **Vietnamese**
  - [x] iOS: follows the iPhone's language or the per-app language chosen in iOS Settings (Settings › Change language links there)
  - [x] Dates formatted for the current language (date-fns locales on web, `Date.FormatStyle` on iOS)
  - [x] Purifier model names and filter descriptions shown in the current language, from the bilingual catalog
  - [x] App name on the iOS Home Screen: "Water Purifier" / "Máy Lọc Nước"

## Known limitations

- **Web auth screens are partly English-only.** The sign-in, sign-up and forgot-password forms hard-code their labels, validation and error messages in English instead of using `t()`. Translating them is open work.

Filter and purifier-type names are copied into Firestore when a purifier is created, in the creator's language at that moment. Filter names do not change when the language changes later; model names on the purifier detail screen do, because they are looked up from the catalog by `typeId`.

## Where strings live

| Platform | Location |
|----------|----------|
| Web UI | `web/src/i18n/locales/en.json`, `vi.json` |
| iOS UI | `ios/WaterPurifierManager/Resources/Localizable.xcstrings` (English source, Vietnamese translations) |
| iOS app name | `ios/WaterPurifierManager/Resources/InfoPlist.xcstrings` |
| Catalog | `shared/purifier-types.json` (`{ en, vi }` per text) |
